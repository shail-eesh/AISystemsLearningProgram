## Decisions worth recording

1. **Per-topic packages are uniquely named** (`src/p0_1_oms/`, not `src/`). Fifty-one topics all
   shipping a package called `src` would collide in `sys.modules` the moment pytest collected two
   of them. A root `conftest.py` adds every `phases/*/*/src` to the path, so
   `from p0_1_oms import Order` works from anywhere.
2. **`Money` stores six decimal places and displays four.** Four dp was the obvious choice and it
   failed the benchmark by 28×: a weighted-average cost is a quotient, and re-rounding it on every
   fill accumulates. This is now the worked example in the P0.1 notes and video.
3. **The synthetic order tape was regenerated** so fills never trade through their limit — a real
   book never fills you worse than your limit, and the self-consistency is what lets the replay
   reconcile exactly rather than needing an exception bucket.
4. **pandas stands in for TA-Lib** as P0.2's reference. TA-Lib is a C library that will not build
   in this sandbox; pandas' `rolling`/`ewm` is an independent implementation by other authors,
   which is what a reference is for. Recorded in the topic README with instructions to swap it.
5. **P0.3's benchmark asserts the model does *not* work.** The labels come from a synthetic random
   walk, so the true signal is zero and beating the baseline would mean the protocol is leaking.
   Condition B fails the run if `|z| >= 2`.
6. **Remotion uses the preinstalled Playwright Chromium.** `remotion.media` is not on the network
   allowlist, so Chrome Headless Shell cannot be downloaded; `remotion.config.ts` points
   `setBrowserExecutable` at `/opt/pw-browsers/...`, overridable with `FORGE_CHROMIUM`.
7. **`CodeWalkthrough` highlight timings are relative weights**, stretched over the scene's real
   duration at render time. Authoring absolute frame numbers before the narration exists meant
   the highlights raced ~40 seconds ahead of the voice.

## Bugs found and fixed in our own code

* `(registry or REGISTRY)` in the AlphaDesk registry silently routed registrations to the global
  registry whenever a caller passed a fresh, empty one — `Registry.__len__` returns 0, so an empty
  registry is falsy. Caught by the first test that used it. Now `is None`, and it is the worked
  example for truthiness in the P0.1 notes and video.
* `ChartScene`'s bar chart computed headroom as `max * 1.08`, which moves the wrong way when a log
  scale makes the maximum negative (values of 1e-5). Headroom is now additive.

## Deviations from the plan

* **Episode length.** MASTER_PLAN §5.1 asks for 6–12 minute episodes; these run 14–16. They were
  written as one episode per topic to match Day 1's "3 episodes", and Phase 0's translation-heavy
  material did not compress without cutting content that belongs in the ramp. Pacing itself is on
  target (126–131 wpm, inside the 120–135 band).
  **Fix for Day 2:** `narrate.py` derives `timings.json` from the script's parent directory, so a
  topic can currently hold only one script. Supporting `script-e1.md` → `timings-e1.json` is a few
  lines and should land before T31's five-episode mini-course, where the guideline matters more.
* Nothing else. No GPU topics today, so no `gpu-runner/` entries and no `awaiting-4070` benches.
